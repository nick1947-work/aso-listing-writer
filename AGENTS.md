# Agent guide

Use `skills/aso-listing-writer/SKILL.md` when the user wants Play Store or App Store listing copy, keywords, ASO, or a listing rewrite. Read it first and follow it.

- Never invent search volumes or rankings; label keyword priorities as hypotheses unless the user provides data.
- Do not use banned title words ("best", "#1", "free", "new") or keyword stuffing.
- Run `scripts/check_listing.py` on the draft before presenting it.
