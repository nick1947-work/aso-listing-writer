# Agent guide

This repo holds reusable skills in `skills/<name>/SKILL.md`. When a task matches a skill below, read that skill's `SKILL.md` first and follow it; load files from its `references/` and `assets/` only as the skill directs.

- `skills/play-release-readiness/`: use when the user wants to publish or release an Android/Flutter app on Google Play, asks "is my app ready", has a rejection or policy warning, needs a privacy policy / terms / account-deletion page / Data safety answers, or wants a launch-and-scale plan.
- `skills/aso-listing-writer/`: use when the user wants Play Store or App Store listing copy, keywords, or ASO.

Rules that apply to every skill here:
- Verify date-sensitive rules before stating them (see `play-release-readiness/references/current-requirements.md`).
- Never promise store approval. Report what was checked and what could not be checked.
- Legal documents are templates, not legal advice; do not invent facts about the user's app.
