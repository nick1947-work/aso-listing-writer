# India market notes for ASO

Treat these as starting hypotheses. Confirm with Play Console search-term data when available.

## Search behaviour
- Many users search in Hinglish (Hindi written in Latin script) or mix English nouns with Hindi verbs. Check store autocomplete for the topic before assuming English-only.
- Short, task-based queries are common ("photo se text", "bill scanner", "video player 4k"). Include task phrasing in the full description where it reads naturally.
- Regional-language search matters in Tamil, Telugu, Marathi, Bengali, Kannada, Gujarati and others. Prioritise languages by the app's actual audience, not by population alone.

## What Indian users value (use only when true for the app)
- Works offline / low data usage
- Small APK size, runs on low-RAM Android devices
- No login or mobile-number requirement
- No intrusive ads; clear, upfront permission use
- Privacy: data stays on device
- UPI, GST, rupee-aware features for finance/billing apps
- Hindi or regional-language UI

## Listing tips
- Lead with the benefit users feel (saves time, saves data, works without internet) before technical details.
- Screenshots and feature graphic carry a lot of conversion weight: caption them with the same primary keyword and benefit, in Hindi as well where the audience warrants it.
- Add Hindi (and other) localized listings through Play Console translations; they index separately by language.
- Do not claim government, bank, or payment-network affiliation (UPI, NPCI, RBI, etc.). Describe compatibility factually.
